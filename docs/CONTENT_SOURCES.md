# Content Sources

## Primary Reference
- Microsoft Learn - Azure Fundamentals (AZ-900): https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/
  - Used to align topic categories: Cloud Concepts, Azure Architecture and Services, Azure Management and Governance

## Content Creation
All questions, explanations, flashcards, analogies, and quest scenarios in this project are **original content** created for educational purposes.
- No actual exam questions, exam dumps, or recalled live exam questions were used
- African contexts (Kenya, Nigeria/Mombasa, university/market examples) were added to improve relatability for African learners
- Analogies include notes about where they differ from actual Azure implementations

## Verification Notes
- Shared responsibility varies by service model and configuration - reflected in content
- Availability Zones are within a region; Region Pairs are for disaster recovery - distinguished clearly
- IaaS/PaaS/SaaS responsibility split is covered with correct emphasis on customer always being responsible for data
- No guarantees of exam pass rates or official Microsoft policies are stated
